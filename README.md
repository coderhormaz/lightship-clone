# Lightship Clone

A front-end clone of the Lightship website, built as a design practice project. The centrepiece is a frame-by-frame van animation made from a sequence of images.

## Live Demo

https://hormaz-lightship.netlify.app/

## Features

- Single-page recreation of the Lightship site design
- 92-frame van image animation (frames `van00001`–`van00092`)
- Video sections

## Tech Stack

- Plain HTML, CSS and JavaScript

## Getting Started

No install or build step is needed. Just open the page:

```bash
# open this file in a browser
index.html
```

Or host the folder on any static host (Netlify, Vercel, GitHub Pages, etc.).

## Notes

A practice clone made for learning front-end layout and animation — not affiliated with Lightship.
